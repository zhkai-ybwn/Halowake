# Product

## Register

product

## Users

Halowake is for local developers working in desktop project directories. They work alongside AI coding agents (Codex, Claude Code, OpenCode, Antigravity) and need to inspect Git state, prepare commits with AI assistance, manage project run/build tasks, review code, and track sessions from the same workspace.

## Product Purpose

Halowake turns a selected project directory into a focused desktop workbench. Success means a developer can understand the current project state, choose the right files, generate or edit a commit message, and run the necessary project actions without losing context.

## Brand Personality

Restrained, professional, efficient. A local-first companion for AI coding workflows.

## Anti-references

Halowake should not feel like a marketing page, a decorative dashboard, or a novelty AI interface. It should avoid heavy ornamentation, oversized hero patterns, gratuitous motion, and layouts that trade information density for visual flair.

## Design Principles

- Keep the selected project as the stable context across tools.
- Make the next action obvious before exposing secondary controls.
- Preserve developer-tool density while separating unrelated decisions.
- Use AI as an assistive layer, not as the center of the workflow.
- Prefer familiar desktop workbench patterns over invented navigation.

## Accessibility & Inclusion

Treat Halowake as a professional desktop tool: maintain readable contrast, visible focus states, keyboard-reachable primary actions, and status text that is not conveyed by color alone.
