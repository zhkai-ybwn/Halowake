# Halowake v1.4.6 Release Notes

> **AI Coding 时代的本地开发伴侣 —— 工作日报跨 Agent 历史会话全量覆盖、OpenCode 数据库直读、状态即时联动与 Git Assistant 安全隔离加固**

---

## 🚀 版本亮点 (Highlights)

### 1. 📊 工作日报多 Agent 历史会话全量覆盖与精准还原 (Comprehensive Work Report History Recovery)
- **Codex 压缩与归档记录深度解析**：
  - 引入 Zstandard（`zstd`）流式只读解压能力，全量覆盖 `.jsonl.zst` 压缩归档文件与原生 `.jsonl` 记录；
  - 完整扫描 `sessions` 与 `archived_sessions` 归档目录，兼容自定义 `CODEX_HOME` 环境变量；
  - 彻底废除按存储目录月份粗粒度剪枝与文件修改时间（mtime）排除逻辑，确保导入或跨月的历史消息绝不遗漏。
- **续聊会话去重与多段消息合并**：
  - 底层基于 `(provider, session_id)` 会话级键值进行消息序列聚合，先完整合并跨文件续聊上下文再判定有效工作内容（`hasWorkContent`），彻底解决续聊文件重复统计或分散问答被误排的问题。
- **OpenCode 数据库直读与旧存储平滑兼容**：
  - 新增专用解析模块，支持对 OpenCode 本地 SQLite（`opencode.db`）中的 `session` / `message` / `part` 进行只读联合查询，按真实消息时间戳精准过滤并组装文本；
  - 完整保留对根目录嵌入式 JSON 与历史拆分目录存储的支持，兼容 `XDG_DATA_HOME`；
  - 项目自动发现与工具检测同步覆盖 SQLite 数据库，使得 OpenCode 历史会话无缝纳入统计。
- **Claude Code 嵌套提取与工作区适配**：
  - 修复 `message.content` 嵌套正文文本的提取路径，直接读取会话内的真实工作区（`cwd`）与真实 `sessionId`；
  - 兼容 `CLAUDE_CONFIG_DIR`、压缩归档及嵌套子代理（Subagent）记录，并保持子代理独立身份。
- **Antigravity 工作区溯源与映射加固**：
  - 优先使用本地数据库映射解析工作区归属；
  - 允许通过查询区间之前的历史工具调用路径向上推断工作区归属，同时严格保证期外正文不进入日报；
  - 项目发现列表自动纳入在会话数据库中有记录的工作区。
- **统一真实时间戳精确比对**：
  - 全部工具统一采用 UTC 真实时间点（`DateTime<Utc>`）进行时区中立的区间比对，彻底解决 ISO 8601 时区偏移与毫秒精度不一致引起的边界漏读问题。

### 2. ⚡ 日报交互体验与响应式状态机优化 (Interactive Report State Machine & Filtering)
- **自动排除即时生效**：切换自动排除开关无需重新请求后端接口，筛选结果毫秒级即时响应；
- **生成文本与筛选即时联动**：勾选会话、调整项目白名单、更改关键词时，自动生成的 Markdown 文本实时同步更新；
- **用户手动编辑保护**：若用户已在生成文本上进行手工修改，后续筛选变动自动保留用户编辑并友好提示手动重新生成，杜绝用户成果被意外冲掉；
- **防竞态与无白名单全选**：引入加载请求序列号，防止慢速网络或过期结果覆盖最新筛选；项目全选采用无白名单模式，后续新加载的项目不会被旧全选列表过滤；
- **跨跨度日期范围完整展示**：多日或季度导出标题明确展示完整起止日期范围（如 `2026-07-01 ~ 2026-09-30`），各条目展示清晰的年月日与时分。

### 3. 🛡️ Git Assistant 外部 Diff 隔离与合并冲突快照加固 (Git Assistant Hardening & Diff Isolation)
- **外部 Helper 与脚本隔离**：为底层 Git Diff 增加 `--no-ext-diff` 与 `--no-textconv` 参数，防止外部未知或恶意的 diff 驱动/helper 在无感知状态下被调用；
- **冲突状态快照延迟统计**：在仓库处于 `unmerged` 冲突状态时，自动推迟耗时的行级变更统计，杜绝冲突扫描引起的挂起或状态污染；
- **前端 Diff 请求防竞态**：引入 `diffRequestId` 序列，快速切换文件时始终以最新请求为准；当 Diff 抽屉或内联面板折叠时，及时清空旧 Diff 数据释放内存。

### 4. 🛡️ 全栈工程门禁 100% 绿色达标 (100% Quality Gates Passed)
- 前端 TypeScript（`vue-tsc`）、`eslint` 代码风格与 `stylelint` 样式检查 0 错误 0 警告；
- 前端核心单元测试 54/54 全量通过；
- 前端生产环境编译（`vite build`，共 4,818 模块）打包成功；
- Rust 后端单元测试 155/155 全量通过；
- Rust 技能中心 FTS5 注册表集成测试 11/11 全量通过。

  - 新增 OpenCode 本地 SQLite 只读查询解析模块，提取 `session`、`message`、`part` 数据并支持按真实时间段过滤；

前往 [GitHub Releases](https://github.com/zhkai-ybwn/Halowake/releases/tag/v1.4.6) 下载对应架构安装文件：
