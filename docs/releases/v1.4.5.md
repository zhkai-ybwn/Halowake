# Halowake v1.4.5 Release Notes

> **AI Coding 时代的本地开发伴侣 —— Codex 配额预热确认机制修复、证据链校验与全栈稳定性增强**

## 🚀 版本亮点 (Highlights)

### 1. 🐛 Codex 配额预热确认机制修复与证据链闭环 (Codex Quota Warmup Confirmation & Verification)
- **修复滑动时间戳误判**：针对旧版本中当模型推理未完成或未触发真实窗口时，因未使用配额窗口返回动态滑动的 `now + 5h` 重置时间戳而可能被误判为成功的缺陷，本版本彻底废除单一时间戳位移判定逻辑，坚决不再将移动的 reset 时间视作成功证据；
- **严密的三重要素证据链**：
  1. **完整会话轮次**：必须确认底层匹配的临时沙箱 thread 与 turn 已真正执行完成；
  2. **模型回复或输出 Token**：必须捕获到模型实际输出文本（`reply_received: true`）或正向计量的 Token 消耗（`output_tokens > 0`）；
  3. **窗口固定重置证据**：当消耗展示因四舍五入为 0 时，必须在相隔至少 1 分钟的探测中观察到固定倒计时递减，确认配额周期已真正锚定锁定；
- **沙箱准备与派发标记时序优化**：
  - 模型探测与临时沙箱 thread 创建移至持久化派发标记之前，彻底杜绝初始化阶段异常导致的僵死状态；
  - 模型生成响应等待时间设定为 120 秒安全上限，并在节点配额窗口周期内严格受控；
  - 验证阶段限定在最长 3 分钟内完成，超时安全退出，**绝不二次自动重试派发推理**，保障用户额度安全；
- **历史旧数据平滑校正**：
  - 应用启动加载时，自动识别并更正旧版本遗留的未确认成功记录，明确标识为“旧版未确认”，绝不自动补发请求或篡改用户排期配置；
- **阶段诊断透视与中英文案对齐**：
  - 前端调度面板支持查看实时请求阶段诊断（连接 Codex、读取额度、读取模型、创建临时会话、发送请求、等待模型完成、模型请求已完成）；
  - 全量补齐中英双语国际化文案与状态说明。

## 🛠️ 详细变更清单 (Changelog)

### 配额中心与预热调度 (Quota Hub & Scheduler)
- `src-tauri/src/quota/scheduler/codex.rs`：
  - 引入 `WarmupEvidence` 结构体，捕获 `stage`、`model`、`thread_id`、`turn_id`、`reply_received`、`output_tokens` 与脱敏服务错误；
  - 新增 `PreparedWarmup` 预处理阶段，提前分离模型准备与实际请求派发；
  - 收集底层 RPC 事件（`item/completed`、`thread/tokenUsage/updated` 等），严格校验模型生成完成；
- `src-tauri/src/quota/scheduler/mod.rs`：
  - 状态机重构：分离基准 reset 与确认 reset，引入固定倒计时至少 1 分钟观测验证；
  - 启动阶段自动修复历史未证实数据；
  - 丰富单元测试用例，覆盖全部修复分支；
- `src/services/quota/quota-scheduler.ts`：
  - 扩展 `CodexScheduleRun` 契约，支持 `requestEvidence` 与 `requestError` 字段；
- `src/components/quota/CodexScheduleModal.vue`：
  - UI 增加请求阶段指示与证据状态展示；
- `src/i18n/messages/zh-CN.ts` & `src/i18n/messages/en-US.ts`：
  - 增补阶段诊断与历史修正文案。

### 版本发布与工程元数据 (Release & Metadata)

## 📦 安装与升级 (Installation)

### 方式一：下载桌面安装程序
前往 [GitHub Releases](https://github.com/zhkai-ybwn/Halowake/releases/tag/v1.4.5) 下载对应架构安装文件：
- **Windows x64 安装程序**（首发推荐）：`Halowake_1.4.5_x64-setup.exe` (支持平滑覆盖升级)
- **macOS / Linux**：推送 `v1.4.5` 标签后由 GitHub Actions 自动化矩阵流水线统一构建并分发对应镜像。

### 方式二：应用内检查更新
已安装 Halowake 的用户可在应用设置中点击 **检查更新**，直接下载最新稳定补丁包完成一键无缝升级。
