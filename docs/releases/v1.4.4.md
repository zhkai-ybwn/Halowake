## 🚀 版本亮点 (Highlights)

### 1. ⏰ Codex 配额定时预热调度中枢 (Codex Quota Schedule & Warmup)
- **滚动配额痛点破局**：针对 Codex 订阅制的 5 小时滚动配额刷新机制，新增轻量级、安全、受控的定时预热功能。在预设时间节点自动发起轻量探测，提前唤醒并开启新的配额周期，避免工作繁忙时因未及时激活而导致可用额度不足；
- **灵活自主的排期规则**：
  - 默认推荐配置为工作日（周一至周五）的 `08:00`、`13:00`、`18:00` 节点；
  - 支持自定义任意时间点列表、生效星期、轮询检查间隔（30s / 60s / 120s / 300s）与最大等待超时窗口（5 ~ 60 分钟）；
  - 提供即时单次执行（立即检查/预热）与一键暂停/恢复控制；
- **高等级安全沙箱隔离**：
  - 每次预热均在独立创建的临时目录与干净工作空间中执行（严格隔离 `CODEX_HOME`）；
  - 采用官方 Codex app-server 协议进行通信，仅临时复制当前本地 ChatGPT 登录会话凭据，**绝不包含 refresh token、用户本地配置、外部 MCP 工具或任何自动化 Hooks**；
- **单节点防重消费与熔断退避**：
  - 每个时间节点严格限制最多发起一次预热请求，并在请求派发前先行持久化记录；
  - 遇到模糊或待确认网络结果时仅做只读探测验证，坚决不重复调用消耗额度；
  - 内置指数退避算法，连续 5 次瞬态网络错误自动熔断退出，鉴权失效或协议异常立即终止当前节点；
- **透明审计与零凭据留存**：
  - 运行状态与最近 20 条调度历史统一存入本地 SQLite `app_metadata`；
  - 仅记录时间戳、状态标签、等待耗时与次数，严禁记录任何凭证、私钥或未经脱敏的 RPC 错误。

### 2. 🎨 DevDock 进程控制面板样式防错位与层次重构 (DevDock Process Header Alignment)
- **操作按钮绝对防折行**：彻底修复当“端口排查”与“清空已完成”操作同时出现时，由于 Flex 容器被压缩导致的汉字换行与高度溢出问题；全面引入 `white-space: nowrap`、`flex-shrink: 0` 与精准文字行高控制；
- **主副标题视觉层级规范**：
  - 将主标题规范为高对比度、清晰加粗的 **进程管理**；
  - 将副标题（“快速停止、重启和查看日志”）降级为辅助说明，在空间受限时支持单行优雅省略（`text-overflow: ellipsis`）并提供原生完整悬浮气泡提示；
- **关闭按钮尺寸协同**：关闭按钮升级为 `size="sm"`（24px），与 26px 的操作按钮在视觉中线处达到严整对齐；
- **侧边栏网格列宽优化**：优化展开状态下侧边栏的响应式网格列宽（调整为 `minmax(340px, 380px)`，窄屏 `<=980px` 为 `minmax(300px, 340px)`），为进程卡片信息提供更舒适的阅读排版空间。

## 🛠️ 详细变更清单 (Changelog)

- `src-tauri/src/quota/scheduler/mod.rs`：实现基于 Tokio 的定时调度工作线程、节点状态机、SQLite 持久化与 Tauri 命令接口；
- `src-tauri/src/quota/scheduler/codex.rs`：实现临时沙箱环境构建、官方 app-server 协议握手与安全预热调用；
- `src-tauri/src/quota/mod.rs` & `src-tauri/src/lib.rs`：注册 `load_codex_schedule`、`save_codex_schedule`、`run_codex_warmup_now` 后端指令与后台常驻任务启动逻辑；
- `src/components/quota/CodexScheduleModal.vue`：新增 Codex 定时预热配置模态窗，支持时间节点选择、工作日勾选、轮询间隔设定与历史节点审计；
- `src/components/quota/QuotaManagerModal.vue`：在配额中心顶部工具栏增加定时预热入口按钮；
- `src/services/quota/quota-scheduler.ts`：封装与 Tauri IPC 交互的预热调度服务契约；
- `src/i18n/messages/zh-CN.ts` & `src/i18n/messages/en-US.ts`：完成预热功能全部文本的中英双语国际化适配；

### 进程管理与 DevDock (DevDock & Process Management)
- `src/views/devdock/components/DevDockProcessPanel.vue`：重构顶部 Header 弹性盒布局，添加防压缩、防折行样式，优化主副标题层级与关闭按钮规格；

## 📦 安装与升级 (Installation)

### 方式一：下载桌面安装程序
前往 [GitHub Releases](https://github.com/zhkai-ybwn/Halowake/releases/tag/v1.4.4) 下载对应架构安装文件：
- **Windows x64 安装程序**（首发推荐）：`Halowake_1.4.4_x64-setup.exe` (支持平滑覆盖升级)
- **Windows x64 便携程序**：`Halowake.exe`
- **macOS / Linux**：推送 `v1.4.4` 标签后由 GitHub Actions 自动化矩阵流水线统一构建并分发对应镜像。

### 方式二：应用内检查更新
已安装 Halowake 的用户可在应用设置中点击 **检查更新**，直接下载最新稳定补丁包完成一键无缝升级。
