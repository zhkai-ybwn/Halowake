# Halowake v1.6.1

- 修复 Git 助手使用 OpenAI 官方接口生成提交信息时报 HTTP 400 的问题。请求采用适用于 GPT-6.2 Sol 的参数。
- OpenAI 官方接口的「测试连接」会检查所填的模型 ID。使用 GPT-6.2 Sol 时，请在「模型 ID」中填写 `gpt-6.2-sol`。
- 生成失败时，Git 助手显示实际错误，便于定位配置和接口问题。

---

## English

- Fixed HTTP 400 errors when generating Git commit messages through the official OpenAI API. Requests now use parameters compatible with GPT-6.2 Sol.
- Test Connection checks the configured model ID for the official OpenAI API. Enter `gpt-6.2-sol` in the Model ID field to use GPT-6.2 Sol.
- Git Assistant shows the underlying error when generation fails, making configuration and API problems easier to diagnose.
