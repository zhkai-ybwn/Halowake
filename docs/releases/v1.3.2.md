# Halowake v1.3.2 Release Notes

> **AI Coding 时代的本地开发伴侣 —— 主流 AI 编程助手全量接入、本地凭据安全解密、极速乐观扫描与 macOS 原生体验深度重构**

---

## 🚀 版本亮点 (Highlights)

### 1. 🤖 主流 AI 编程助手与客户端全量接入 (6 大新生态)
针对开发者本地常用的 AI 编程环境，v1.3.2 实现了跨平台本地凭据深度挖掘、安全解密与云端额度实时同步：
- **WorkBuddy (腾讯混元 / 企微智能助手)**：
  - 自动扫描本地认证会话，联动腾讯底层 `get-user-resource-free-packages` 与 `paid-packages` 接口；
  - 精确区分并呈现「个人版月度基础包 (按月自动重置)」与「运营裂变加赠包 / 营销活动包」；
  - 明确展示 `CycleEndTime` 到期截止时间戳（如 `2026-09-30 23:59:59`）与天数倒计时（如 `剩 20 天 · 09-30 到期`）。
- **阿里灵码 (通义灵码 / Qoder CN)**：
  - 自动定位本地配置，在 Rust 端结合系统 DPAPI 与 AES-256-GCM 安全解密用户凭据；
  - 实时查询官方 Status / Plan 接口，展示 Pro Trial / 个人版特权状态与有效期倒计时。
- **Cursor IDE**：
  - 本地解析 SQLite `state.vscdb` 中的 `cursorAuth` 认证集；
  - 识别 Pro / Free 订阅等级及绑定账号邮箱，精准展示 Fast Requests 高速调用额度。
- **Trae (字节跳动 AI IDE)**：
  - 自动解析 `%APPDATA%\Trae CN` 与 `Trae` 的存储和 SQLite 状态库；
  - 读取当前绑定账号，列出已授权激活的核心大模型（Claude 3.5 Sonnet, GPT-5.4, 豆包 Doubao-Seed-2.0, Kimi-K2 等）。
- **Z-Code (智谱 GLM 清言 / 智谱 Code)**：
  - 逆向解密 `~/.zcode/v2/credentials.json` 本地 AES-256-GCM 凭证；
  - 对接智谱官方套餐接口，展示 Start Plan / Pro Plan、每日 3,000,000 Token 配额与截止日期 `ends_at`。
- **OpenCode**：
  - 覆盖 Windows 所有用户目录与 AppData 安装路径，正确解析默认模型及配置的上游模型提供商通道。

---

### 2. 🎨 遵循 macOS Design 原生设计规范的深度重构
结合 Apple Human Interface Guidelines 与 `macos-design` 规范，对看板进行全方位的视觉降噪与层级提炼：
- **定制 6 大客户端官方高精品牌图标**：
  - 全量上线 Cursor (3D魔方箭头)、阿里灵码 (莫比乌斯环Q)、OpenCode (终端光标框)、Trae (8-bit Pixel Pal萌宠双眼)、WorkBuddy (猫耳萌宠)、Z-Code 的高分辨率官方图标。
- **移除卡片内多层滚动条，恢复高度自适应**：
  - 彻底去除卡片内部 `.card-content-top` 的 `overflow-y: auto` 与自定义滚动条，告别“全屏都是细小滚动条”的视觉凌乱；
  - 卡片内容自然完整展开，配合 CSS Grid 的自动拉伸特性，同行卡片自动等高对齐，一眼掌握全部信息。
- **物理级底部安全呼吸留白 (Bottom Margin)**：
  - 攻克 WebKit / Chromium（WebView2）Flex 滚动容器忽略 `padding-bottom` 的经典规范缺陷；
  - 注入实体 DOM 留白占位条，确保滚动至最底部时，最底排卡片与软件窗口底边保持 64px 的开阔呼吸间距，不再贴底。
- **信息层级降噪与文本去重**：
  - 精简套餐标签，避免挤压主标题（彻底解决“阿里灵码 (Qoder ...)”标题截断）；
  - 智能补全副标题（如 `Alibaba Cloud · 阿里云通义灵码`、`Anysphere · Cursor AI 编辑器`），消除主副标题 100% 重复的问题；
  - 去除订阅型卡片上突兀的“预估耗尽 100%”硬编码显示，消除与“节奏健康”的语义自相矛盾；
  - **额度超标预估百分比严格取整**：前后端统一将配速健康预测（Pace）与周期超标预估百分比（如 `121.4928...%`）严格格式化为纯整数（如 `121%`），消除长小数位带来的视觉噪点；
  - 去除 Z-Code 算力条目中三重套娃的 `(每日重置 (Daily) token)` 重复文本。
- **精细化业务单位体系**：
  - 告别粗暴的通用“点”单位，赋予精准业务含义：Trae 为 `4 / 4 个模型`、阿里灵码为 `1 项特权生效中`、OpenCode 为 `1 个模型 / 2 个通道`、Cursor 为 `500 次`、Z-Code 为 `Tokens / 日`。

### 3. ⚡ 一键扫描极速体验与歧义根除 (Zero-Delay UX)
- **即时雷达扫描横幅**：点击扫描瞬间 0ms 展开动态脉冲进度条，消除无反馈感；
- **100ms 乐观卡片注入**：本地探测到凭据后，先在 100ms 内生成骨架占位卡片，打消用户等待焦虑；
- **根治提示时序歧义**：
  - 扫描时自动切回“全部”分类，防止新卡片被特定 Tab 规则过滤屏蔽；
  - 严格等待后台全量云端数据更新完毕后再弹出提示，杜绝“提示已存在、界面却未渲染”的时序错位；
  - 分流精准提示：“成功新发现 X 个账号”与“已同步 X 个本地凭据，当前列表均为最新额度”。

## 📦 安装与升级 (Installation)

### 方式一：应用内无缝自动更新（推荐）
- 已安装旧版本的用户在应用内点击 **检查更新**，即可自动拉取并无缝升级至 `v1.3.2`。

### 方式二：下载桌面安装包
前往 [GitHub Releases](https://github.com/zhkai-ybwn/Halowake/releases/tag/v1.3.2) 下载对应平台的安装程序：
- **Windows**: `Halowake_1.3.2_x64-setup.exe` (NSIS 安装包，无缝覆盖安装)
- **macOS**: `Halowake_1.3.2_universal.dmg` (Apple Silicon M系列与 Intel 通用镜像)
- **Linux**: `Halowake_1.3.2_amd64.deb` / `.AppImage`

## 🔒 隐私与本地优先承诺 (Local-First)
- **0 云端中转**：所有本地客户端凭据、Cookie、Token、API Key 及算力查询全量由本地设备直接发起；
- **直连各大厂商官方服务**：不设任何中间代理服务器，最大程度保护开发者的资产与隐私安全。
