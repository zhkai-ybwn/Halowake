# Halowake v1.4.0 Release Notes

> **AI Coding 时代的本地开发伴侣 —— 全新 Agent 技能中心重磅上线、工作台与导航架构现代化重构、AI 额度中心全局模态化与组件原子级解耦、Git 助手与 DevDock 体验与底层性能极致跃升**

---

## 🚀 版本亮点 (Highlights)

### 1. 🔮 全新 Agent 技能中心全量上线 (Multi-Agent Skills Ecosystem)
构建面向下一代 AI 编程生态的 Agent 技能统一发现、状态感知与一键更新中枢：
- **多平台技能生态智能感知**：统一支持探测并聚合管理 Cursor、Antigravity、Claude Code、Trae、Qoder、OpenCode、Windsurf、Cline 以及项目专属技能；
- **智能 Frontmatter 元数据解析**：原生支持 `SKILL.md` 中 YAML 标量、折叠标量（`>-`、`|-`）与元数据字段解析，精准呈现技能名称、版本号与详细描述；
- **Git 仓库版本追踪与安全更新**：自动感知各技能目录的 Git 远端地址、当前分支、落后提交数（`commits behind`）以及本地脏改动防护（`is_dirty` 拦截与安全提示），支持单技能更新与一键全部更新；
- **便捷快速定位**：支持一键在系统文件管理器中打开技能目录，便于开发者自定义扩展与调试；
- **顶部技能胶囊与全局入口**：顶部导航栏新增 `TopbarSkillsPill` 技能胶囊组件，实时展现技能总数与可用更新状态，支持直接弹窗唤起管理面板；同时集成到全局快捷命令面板（Command Palette）。

### 2. 🎨 工作台与侧边栏现代化 Mac 风格导航重构 (Modern Mac Shell & Refactored Navigation)
全面升级应用骨架交互与视觉层次：
- **功能分组与清晰信息架构**：侧边栏严格划分为两大板块 —— **【工作区】**（DevDock、Git 助手）与 **【实用工具】**（Markdown 预览、AI 日报），层次更分明；
- **全新 AppNavIcon 矢量组件**：抽离专用图标渲染层，侧边栏折叠/展开与激活态增加优雅的高光与阴影过渡微交互；
- **统一通用关闭按钮 (WorkbenchCloseButton)**：规范抽屉（Drawer）、模态面板（ModalPanel）、Sheet 及 Naive UI 对话框顶部的关闭按钮尺寸、动效与无障碍聚焦表现；
- **无用模块深度净化**：彻底清理遗留的旧版 HomeView、Sidebar 冗余组件及无用静态配置。

### 3. 💳 AI 额度中心全局模态化与组件原子级解耦 (Modal Quota Center & Decoupled Architecture)
- **模态浮层化蜕变**：告别原全屏页面路由跳转，重构为随处可唤起的全局模态浮层 `QuotaManagerModal`，可在任何工作流中即点即用，用完即关；
- **卡片组件原子级拆分**：将原本庞杂的 `QuotaCard` 深度解耦为职责单一的高内聚原子子组件：
  - `QuotaCardBalance`（模型余额与免费额度展示）
  - `QuotaCardCredits`（通用算力点数看板）
  - `QuotaCardPace`（消耗节奏与预计可用时长测算）
  - `QuotaCardRateLimit`（RPM / TPM / 5小时 / 每周速率限制）
- **顶部额度胶囊紧凑升级**：`TopbarQuotaPill` 与全新模态无缝联动，增加紧迫状态呼吸灯，并支持快捷键一键唤起。

### 4. ⚡ Git 助手提交生成与二次确认体验升级 (Git Assistant AI Commit & UX Boost)
- **AI 提交生成工具栏**：在提交区域引入专属 AI 生成状态条，直观呈现当前推理模型、提示词多语言目标，以及分步脉冲动画指示灯；
- **防误触二次确认保护**：在已有提交说明时重新生成，自动弹出防覆盖确认框（`NPopconfirm`），防止用户心血被意外冲掉；
- **操作按钮强视觉呈现**：提交按钮升级为全宽主要操作按钮，动态呈现当前平台提交快捷键（`Ctrl+Enter` / `⌘+Enter`），并规范对话框交互。

### 5. 🧩 Codex 工作日报 2000 行单文件深度解构 (Codex Daily Report View Modularization)
- **高内聚组件化拆分**：将 2000 余行的庞大单文件解构为清晰的子组件集群：
  - `CodexSessionList`（多会话列表与时间分组渲染）
  - `CodexReportEditor`（日报 Markdown 编辑器与工具栏）
  - `CodexReportFilterStrip`（顶部筛选工具条与日期范围选择）
  - `CodexProjectFilterModal`（多项目精准筛选浮层）
  - `CodexPromptDrawer`（Prompt 提示词模板抽屉）
- **性能与类型安全性兼备**：保持全部历史会话跨日加载与 SQLite 关系映射的卓越性能，同时大幅降低后续迭代的认知负荷。

### 6. 🚀 DevDock Windows 平台进程保活底层优化 (Win32 API Process Runtime)
- **底层 API 极速替代**：在 Windows 平台上，用轻量底层的 Win32 原生 API（`OpenProcess` 与 `GetExitCodeProcess`）彻底取代原先开销巨大的 `tasklist /FI PID eq ...` 外部命令行轮询；
- **大幅降低系统开销**：消除频繁创建外部子进程造成的 CPU 瞬时飙升与磁盘开销，进程保活探测性能提升一个数量级。

### 7. 🧹 代码库架构精简与规范演进 (Codebase Cleanup & Decoupling)
- **Composables 规范化**：废弃 `src/hooks/` 目录，统一迁移并规范化为 `src/composables/`；
- **双语国际化全量覆盖**：中英文语言包补齐 Agent 技能中心、提交助手、额度中心状态等全部新词条；
- **全局 SCSS 细节打磨**：微调 Naive UI 卡片关闭按钮与各主题下的配色对比度。

- `src-tauri/src/commands/skills.rs`：新增 Agent 技能扫描、版本与更新状态检测、本地 Git 更新执行与目录打开等核心后端接口；

- `src/components/quota/QuotaManagerModal.vue`：全新 AI 额度中心模态浮层；
- `src/components/quota/card/`：解耦新增 `QuotaCardBalance.vue`, `QuotaCardCredits.vue`, `QuotaCardPace.vue`, `QuotaCardRateLimit.vue`；
- `src/components/common/AppNavIcon.vue`：抽离统一导航图标组件；

- `src/views/git-assistant/components/GitCommitAssistant.vue`：新增 AI 生成状态栏、进度指示器、覆盖确认框及全宽快捷键提交按钮；

## 📦 安装与升级 (Installation)

### 方式一：应用内无缝自动更新（推荐）
- 已安装旧版本的用户在应用内点击 **检查更新**，即可自动拉取并无缝热升级至 `v1.4.0`。

### 方式二：下载桌面安装包
前往 [GitHub Releases](https://github.com/zhkai-ybwn/Halowake/releases/tag/v1.4.0) 下载对应平台的安装程序：
- **Windows**: `Halowake_1.4.0_x64-setup.exe` (NSIS 安装包，无缝覆盖安装)
- **macOS**: `Halowake_1.4.0_universal.dmg` (Apple Silicon M系列与 Intel 通用镜像)
- **Linux**: `Halowake_1.4.0_amd64.deb` / `.AppImage`
