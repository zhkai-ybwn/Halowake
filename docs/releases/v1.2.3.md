# Halowake v1.2.3 Release Notes

> **AI Coding 时代的本地开发伴侣 —— Codex 限额重置次数与过期时间透视、空 Diff 自动校准修复与全量品牌清理**

---

## 🚀 版本亮点 (Highlights)

### 1. 🔄 Codex 限额重置次数与过期时间深度透视 (Rate Limit Resets & Expiry)
- **实时重置次数监控**：在 AI 额度管理卡片及头部徽标中新增 Codex 限额重置机会（`Rate Limit Reset Credits`）的可用次数显示。
- **精确过期时间与倒计时**：自动聚合计算最近到期重置机会的过期时间戳与剩余天数/小时数（如 `9月20日 · 16天后` / `最近将于 9月20日 22:56 (16天后过期)`），限额用尽前做到心中有数。
- **气泡与明细面板联动**：卡片头部标签 tooltip 与下部限额重置卡片均提供细致的到期提醒与状态引导。

### 2. 🛡️ Git 变更浏览器空 Diff 幽灵状态与提交死锁自动校准
- **空 Diff 自动识别与安全放行**：针对因 CRLF/LF 行尾符跨平台格式化或 Git index 缓存脏状态导致的“文件有变更标记但 diff 显示为空无法提交”的问题，提交引擎新增空 Diff 校验机制。
- **自动索引对齐**：智能校准本地暂存区，避免脏备份暂存区覆盖，彻底解决“提示修改却提交失败”的死锁问题。

### 3. 🏷️ Halowake 品牌全量沉淀与文案一致性修补
- **操作弹窗与窗口标题**：修补 Git 操作执行弹窗、Diff 独立比对窗口、Log 历史回溯窗口中的遗留品牌名称为 **Halowake**。
- **AI 评审与分享文案**：同步修正 AI 代码评审 Prompt 系统标识与额度快速分享文案（`via Halowake`）。

## 🛠️ 详细变更与优化 (Changelog)

### 💳 额度管理 (AI Quota)
- **后端接口聚合**：通过 `tokio::join!` 并行拉取 `/wham/usage` 与 `/wham/rate-limit-reset-credits`，零额外耗时获取可用重置额度与到期明细；
- **RFC3339 日期纳秒/微秒解析**：新增健壮的日期解析逻辑，兼容带小数秒格式的时间字符串并计算 Unix 秒级时间戳；
- **多语言适配**：中英文双语环境均适配到期时间与重置机会文案模板。

### 🌿 Git 核心与工作流 (Git Engine)
- **`src-tauri/src/git/runner.rs`**：`commit_changes_with_progress` 在暂存后检查 `staged_diff_raw`，当内容为空时执行 index 校准并正常返回，避免无效 commit 调用失败；
- **单元测试补充**：新增 `commit_phantom_diff_calibrates_index_and_succeeds` 自动化单元测试。

## 📦 安装与升级 (Installation)

### 方式一：下载桌面安装包
前往 [GitHub Releases](https://github.com/zhkai-ybwn/Halowake/releases/tag/v1.2.3) 下载对应系统安装包：
- **Windows**: `Halowake_1.2.3_x64-setup.exe` (NSIS 安装程序，支持旧版本平滑升级与快捷方式自动维护)
- **macOS**: `Halowake_1.2.3_universal.dmg` (Apple Silicon & Intel 双架构)
- **Linux**: `Halowake_1.2.3_amd64.deb` / `.AppImage`

### 方式二：应用内在线热更新
- 已安装用户可在应用内直接点击 **检查更新**，自动下载并无缝安装 `v1.2.3`。
