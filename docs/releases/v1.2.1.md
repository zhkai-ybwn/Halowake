# Halowake v1.2.1 Release Notes

> **AI Coding 时代的本地开发伴侣 —— 品牌全面升级与核心架构模块化重构**

---

## 🚀 版本亮点 (Highlights)

### 1. 🌟 全面品牌升级：正式更名为 Halowake
- **全方位视觉与发布统一**：系统托盘菜单（“显示 Halowake”）、托盘悬停气泡、应用主窗口标题、NSIS 安装向导、`package.json` 与 `Cargo.toml` 包名均全面统一为 **Halowake**。
- **向下无缝兼容**：严格遵循“用户可见全面统一，底层兼容完整保留”原则，保留 `com.yubei.lumina`、`lumina.db` 及 `.lumina/` 工作区配置目录，老用户升级**无需迁移数据、原有 Git 提交历史与项目配置零丢失**。
- **新增兼容性规范**：正式落地 `docs/legacy-compatibility.md`，清晰记录所有底层兼容标识符与架构考量。

### 2. 🏗️ 核心系统架构模块化大重构 (Architecture Overhaul)
- **Rust 后端分层解耦**：
  - `git/runner/`：拆分为 `branches`、`diff`、`history`、`process`、`proxy`、`sync` 6 大独立子域；
  - `git/prompt/`：拆分为 `classifier`、`diff_cleaner`、`profile`，实现 Prompt 预算规划与文件结构分析的分层处理；
  - `commands/project_process/`：拆分为 `log_parser` 与 `process_runtime`，提升受管子进程生命周期与 ANSI 日志嗅探的稳定性；
  - `storage/history_repository/`：拆分为 AI 设置、模板、DevDock、Git 提交历史与 Quota 存储 5 大仓储模块。
- **前端 Composables 深度模块化**：
  - 将庞大的 `GitAssistantView.vue` 拆解为 10+ 个聚焦单一职责的 Vue Composables（`useGitSnapshot`、`useGitCommit`、`useGitDiff`、`useGitRemote`、`useGitReview`、`useGitBranchActions`、`useGitBranchOptions`、`useGitStaging`、`useGitConflictDialog`、`useGitRepositorySetup`、`useGitWorkspaceLayout`）；
  - 单独抽离 `GitAssistantView.scss`，界面视图与样式逻辑彻底解耦。

## 🛠️ 详细变更与优化 (Changelog)

### 🔀 Git Assistant
- **历史记录保存加固**：修复重构后 `useGitCommit.ts` 缺少函数导入导致保存提交历史时可能出现的异常。
- **分支与冲突协同**：重构分支切换、合并、变基与冲突解决弹窗逻辑，支持全流程进度追踪与优雅中止。
- **原子暂存保护**：继续强化勾选文件原子提交与暂存区恢复机制，杜绝部分提交导致的暂存污染。

### 🚢 DevDock 本地进程管理
- **进程树级管控**：优化 Windows Job Objects 与跨平台进程树退出机制，保证主程序退出或手动停止时 100% 杀灭衍生后台服务。
- **端口与 URL 嗅探**：优化 ANSI 高亮日志解析性能，毫秒级捕获 `localhost` 服务访问地址与端口。

### 📊 AI Quotas & Code Review
- **Quota 探测优化**：简化本地 Google AI Pro (Antigravity / Gemini) 默认探测链路，提升额度看板加载速度。
- **离线代码审查**：优化审查会话生命周期监听与断网/重启保护，历史审查记录持久化至本地 SQLite。

## 📦 安装与升级 (Installation)

### 方式一：下载桌面安装包
前往 [GitHub Releases](https://github.com/zhkai-ybwn/Halowake/releases/tag/v1.2.1) 下载对应系统安装包：
- **Windows**: `Halowake_1.2.1_x64-setup.exe` (NSIS 安装程序)
- **macOS**: `Halowake_1.2.1_universal.dmg` (Apple Silicon & Intel)
- **Linux**: `Halowake_1.2.1_amd64.deb` / `.AppImage`

### 方式二：从源码构建
```bash
git clone https://github.com/zhkai-ybwn/Halowake.git
cd Halowake
npm install
npm run tauri:build
```
