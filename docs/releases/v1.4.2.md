# Halowake v1.4.2 Release Notes

> **AI Coding 时代的本地开发伴侣 —— Agent 技能生态稳定性加固、FTS5 高精度混合检索演进 (P@1 88.5%)、SQLite 读事务快照隔离、防竞态动态分页与错误重试机制、系统子进程树超时生命周期边界防护**

---

## 🚀 版本亮点 (Highlights)

### 1. 🔍 Agent 技能智能检索与排序全面加固 (Hybrid Search & Ranking Quality)
- **FTS5 全文检索与同义词扩展演进**：深度优化技能注册表 SQLite FTS5 倒排索引与 BM25 加权排序算法，引入精准同义词与意图映射字典；
- **真实基准评测严苛达标**：在包含 30 组生产 Regression 集与 30 组盲测集（含跨语种、缩写、长尾意图等实战样本）的自动化严格评估中，**Strict P@1 准确率达到 88.5%**（超越 88% 的发布质量门槛），Strict MRR@10 达到 0.928；
- **首搜状态与空查询优雅回退**：统一首次搜索、空关键词重置与多维度过滤（Agent/分类/来源）的语义规范，彻底杜绝首次查询丢弃或快照 revision 不一致问题。

### 2. 🗄️ SQLite 读事务快照隔离 (Read Transaction Snapshot Isolation)
- **多游标读取一致性保障**：在 Rust 后端连接池中，为技能检索、统计聚合和详情查询建立严格的同一事务快照生命周期，避免高频写入或后台同步时产生读偏斜；
- **连接泄露防御与健壮容错**：读事务统一纳管并自动释放，消除长时间占用连接导致的连接池耗尽隐患。

### 3. 📄 前端探索区防竞态动态分页与行内重试 (Anti-Race Dynamic Pagination & Retry)
- **请求队列与防抖防竞态控制**：解决用户在技能探索区快速翻页、远距离跳页或在加载中快速点击时的请求时序混乱与数据覆盖；
- **行内错误状态与快速重试**：新增清晰的错误状态提示条与“重新加载”重试按钮，在网络闪断或快照同步超时后无需强制刷新即可就地恢复；
- **状态同步与历史回溯**：修复分页状态与已安装历史页签间切换时的联动异常。

### 4. 🛡️ 进程生命周期与子进程树超时硬边界 (Process Tree Lifetime & Timeout Bounds)
- **全平台子进程树精准治理**：针对 DevDock 与本地进程管理，深度优化 Windows Job Object 与类 Unix 进程组控制；
- **超时强杀与资源防泄露**：确保超时未响应的构建任务、Git 探针或外部 CLI 进程树能被完整清理，彻底解决孤儿进程驻留后台占用端口或内存的问题。

### 5. 🏷️ 工程版本统一与质量门禁全绿 (100% Quality Gates Passed)
- 前端 `package.json`、`package-lock.json`、Rust `Cargo.toml`、`Cargo.lock`、Tauri 配置以及运行时快照版本全量对齐至 `1.4.2`；
- 前端单元测试（43/43 通过）、TypeScript 类型检查与 Lint、前端完整 Build（4,814 模块）、Rust 单元测试（131/131 通过）、搜索集成测试（11/11 通过）全量 100% 绿色通过。

## 🛠️ 详细变更清单 (Changelog)

### 技能中心与检索 (Skill Hub & Search)
- `src-tauri/src/commands/skill_registry.rs`：重构基于事务快照的技能多条件分页查询与统计聚合接口；
- `src-tauri/src/storage/skill_registry_repository.rs`：优化 FTS5 查询权重匹配、同义词展开与结果集倒排过滤；
- `src/stores/skill-explore.ts`：增加防竞态分页请求序列管理、加载中排队与行内重试机制；
- `src/components/skills/explore/SkillExploreView.vue`：优化分页栏、紧凑视图与错误提示 UI 交互；
- `src/utils/skill-synonyms.ts`：增补高频开发者语义与跨语言同义词字典；
- `src-tauri/tests/skill_search_poc.rs`：更新生产基准测试用例与标注，通过 88.5% P@1 验收门槛。

### 进程与系统安全 (Process & System Runtime)
- `src-tauri/src/commands/project_process.rs` & `process_runtime.rs`：加固进程启动、输入输出流捕获与超时强杀边界；
- `src-tauri/src/commands/project_process/port_inspector.rs`：优化本地端口占用探测与跨平台进程关系解析。

### 代码配额与 Git 助手 (Quota & Git Assistant)
- `src/stores/quota.ts` & `src/utils/quota.ts`：修复配额速率计算、缓存刷新时效与多模型提供商识别；
- `src/composables/git-assistant/`：优化快照回溯与审查流程稳定性。

## 📦 安装与升级 (Installation)

### 方式一：下载桌面安装包
前往 [GitHub Releases](https://github.com/zhkai-ybwn/Halowake/releases/tag/v1.4.2) 下载对应安装包：
- **Windows x64 安装程序**（首发推荐）：`Halowake_1.4.2_x64-setup.exe` (支持覆盖升级)
