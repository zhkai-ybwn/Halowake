# Halowake v1.2.2 Release Notes

> **AI Coding 时代的本地开发伴侣 —— Windows 安装向导与热更新平滑迁移修复**

---

## 🚀 版本亮点 (Highlights)

### 1. 🪟 Windows 安装器与旧版 Lumina 自动平滑迁移
- **旧残留自动清理**：修复从 Lumina 在线更新至 Halowake 时可能出现两个软件共存的问题。安装程序现在会自动清理旧版本 `%LOCALAPPDATA%\Programs\Lumina\` 目录以及 Windows 注册表中的旧卸载项。
- **桌面与开始菜单快捷方式迁移**：自动将桌面旧的 `Lumina.lnk` 图标替换为 `Halowake.lnk`，并同步清理开始菜单中的旧入口与冗余副本（如 `(1)`、`- 副本`）。
- **快捷方式生成死锁修复**：彻底修复在特定升级/重装场景下由于更新模式判定导致桌面图标未成功创建的问题，确保每次安装与更新后桌面图标均能稳定呈现。

---

## 🛠️ 详细变更与优化 (Changelog)

### 📦 安装包与更新机制 (NSIS & Updater)
- **`installer-hooks.nsi` 重构**：
  - 移除导致桌面图标创建跳过的 `$NoShortcutMode 1` 限制；
  - 增加对旧版 Lumina 快捷方式、安装目录和注册表键的自动探测与清理逻辑；
  - 在 `POSTINSTALL` 阶段强制确保当前用户桌面存在指向 `Halowake.exe` 的单实例快捷方式并注入正确的 `AppUserModelId`。

## 📦 安装与升级 (Installation)

### 方式一：下载桌面安装包
前往 [GitHub Releases](https://github.com/zhkai-ybwn/Halowake/releases/tag/v1.2.2) 下载对应系统安装包：
- **Windows**: `Halowake_1.2.2_x64-setup.exe` (NSIS 安装程序，支持全自动覆盖升级与旧版本清理)
- **macOS**: `Halowake_1.2.2_universal.dmg` (Apple Silicon & Intel)
- **Linux**: `Halowake_1.2.2_amd64.deb` / `.AppImage`

### 方式二：应用内在线热更新
- 已安装用户可在应用内直接点击 **检查更新**，自动下载并无缝安装 `v1.2.2`。
