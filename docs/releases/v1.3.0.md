# Halowake v1.3.0 Release Notes

> **AI Coding 时代的本地开发伴侣 —— 主流 AI 全厂商额度全景覆盖与积分体系、独立多功能 Markdown 查看器、跨平台交互体验全面升级**

---

## 🚀 版本亮点 (Highlights)

### 1. 💳 主流 AI 工具与全厂商额度全景覆盖 (Full AI Quota & Points Ecosystem)
- **主流厂商与 Agent 全量接入**：
  - **国际与编码 Agent**：Claude Code（Anthropic CLI 凭据自动发现）、OpenCode（Go 计划 / Zen Credits）、OpenAI / Codex、Google Gemini、OpenRouter；
  - **国产大模型与算力底座**：DeepSeek、SiliconFlow（硅基流动）、Moonshot（月之暗面 / Kimi）、智谱 GLM（BigModel）、通义千问（阿里云百炼）、MiniMax（稀宇科技）；
  - **积分与智能体体系**：深度接入 Tencent WorkBuddy（腾讯企点智能体助手积分体系）以及各类 Points / Credits 消耗型工具。
- **三模态统一额度引擎**：
  - **法币余额模式**（CNY / USD）：实时查询与统计账户余额、充值金额与赠送金；
  - **滑动限额模式**（5h / 每周）：精确统计 5 小时与每周额度百分比、重置倒计时、用量配速（健康/用量偏紧/预计超标）及限额重置机会（Reset Credits）；
  - **积分点数模式**（Credits）：监控可用点数与总上限，全量纳入资产大盘。
- **额度中心全新升级 (`AiQuotaView`)**：
  - **新增第 5 块核心指标卡片**：顶部总览新增【总可用积分/点数】，全面掌控各类 Agent 与工具点数资产；
  - **分类筛选 Tab 栏**：支持按【全部】、【国际主流】、【国产算力】、【积分与智能体】快速过滤切换；
  - **全厂商高保真品牌 Logo**：为接入的每一个厂商手工绘制纯矢量 SVG 品牌图标与品牌轻质感底色；
  - **一键分享摘要增强**：一键生成的格式化看板文本无缝包含法币总资产、总可用积分及各厂商明细。

### 2. 🪟 独立多功能 Markdown 查看器 (Standalone Markdown Viewer)
- **独立多窗口渲染**：支持在独立原生窗口中查看 Markdown 研发文档、架构方案与技术笔记，窗口自由调整、最小化与关闭；
- **复杂图表与科学排版全能支持**：
  - **Mermaid 图表引擎**：完整支持流程图、时序图、类图、甘特图、状态图与架构拓扑图的本地实时渲染；
  - **KaTeX 数学公式**：支持行内公式 `\(...\)` 与独立块级公式 `\[...\]`；
  - **复杂表格与代码高亮**：完整支持 GitHub Flavored Markdown 规范表格与多语言代码高亮；
- **大纲目录与左右停靠 (Table of Contents)**：
  - 自动提取文档 H1~H6 标题并生成交互式目录，支持平滑滚动定位与层级高亮；
  - 支持左侧 / 右侧一键换边停靠（Dock Position），彻底修复悬浮触发按钮与侧边栏目录同侧严格对齐，操作自然顺畅；
- **企业加密软件兼容读取**：针对企业亿赛通等终端加密环境，提供原生白名单通道兼容读取，彻底解决企业加密环境下文件无法预览的问题；
- **渲染核心重构**：升级 Markdown 解析器实例绑定流程，彻底修复 `marked.Marked is not a constructor` 异常。

### 3. 🎨 界面细节打磨与跨平台快捷键自适应
- **消除 AI 额度气泡双层边框**：Naive UI 弹出层启用 `raw` 模式，移除冗余外层容器边框与内边距，呈现纯粹 macOS 毛玻璃微边框卡片；
- **跨平台平台修饰键适配**：顶部栏额度卡片与全局快捷键提示自动根据运行环境智能切换（macOS 提示 `⌘5`，Windows/Linux 提示 `Alt+5`）。

## 🛠️ 详细变更与优化 (Changelog)

### 🌐 AI 额度与适配器 (AI Quota & Adapters)
- `src-tauri/src/quota/models.rs`：扩展 `ProviderType` 枚举（Claude, Opencode, Workbuddy, Siliconflow, Moonshot, Zhipu, Qwen, Minimax），`QuotaSummary` 新增 `total_credits` 字段；
- `src-tauri/src/quota/adapters/`：
  - 新增 `claude.rs`：适配 Anthropic API Key 与本地 `~/.claude.json` / `~/.claude` CLI 凭证，5h/周滚动限额与节奏监控；
  - 新增 `opencode.rs`：适配 OpenCode CLI 凭据、Go 计划与 Zen Credits 积分读取；
  - 新增 `workbuddy.rs`：读取本地 `~/.workbuddy` 配置与积分点数；
  - 新增 `siliconflow.rs`：解析硅基流动可用总额、充值余额、代金券；
  - 新增 `moonshot.rs`：解析 Moonshot (Kimi) 现金与凭证余额；
  - 新增 `zhipu.rs`：支持智谱 GLM Coding Plan 限额与开放平台接口；
- `src-tauri/src/quota/discovery.rs`：本地自动扫描引擎扩展，支持同时探测发现 Claude、OpenCode、WorkBuddy、Codex 及内部 `ai-settings.json` 模型配置；
- `src/components/quota/ProviderBrandLogo.vue`：全量补充 8+ 主流大模型与 Agent 的纯 SVG 矢量品牌 Logo；
- `src/components/quota/TopbarQuotaPill.vue`：多模态数值展示逻辑、品牌徽章微底色与滚动网格布局优化；
- `src/components/quota/AccountEditModal.vue`：支持选择全量服务商，为 CLI 工具提供可选 API Key 与自动登录态提示。

### 📝 Markdown 查看器 (Markdown Viewer)
- `src-tauri/src/commands/markdown.rs`：提供跨平台多通道文档读取支持；
- `src/components/markdown/MarkdownDocumentViewer.vue`：支持大纲目录、多样式表格、同侧悬浮切换与双侧停靠；
- `src/services/markdown/markdown-service.ts`：集成 Mermaid、KaTeX、Marked 核心流水线与安全过滤。

## 📦 安装与升级 (Installation)

### 方式一：下载桌面安装包
前往 [GitHub Releases](https://github.com/zhkai-ybwn/Halowake/releases/tag/v1.3.0) 下载对应平台安装包：
- **Windows**: `Halowake_1.3.0_x64-setup.exe` (NSIS 安装包，支持从 v1.2.x 平滑覆盖升级)
- **macOS**: `Halowake_1.3.0_universal.dmg` (Apple Silicon M系列 & Intel 架构双原生通用包)
- **Linux**: `Halowake_1.3.0_amd64.deb` / `.AppImage`

### 方式二：应用内在线更新
- 已安装旧版本的用户可直接在主界面或设置面板点击 **检查更新**，自动拉取并无缝更新至 `v1.3.0`。
