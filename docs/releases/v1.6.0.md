# Halowake v1.6.0

本次更新改进了 Git 工作台在大仓库中的响应，并修复了 Git 写入期间被超时中断的问题。

- **Git 写入更可靠。** 切换分支、合并、拉取后的本地合并和变基都会等待 Git 完成。长时间切换会显示源分支、目标分支和进度。失败后重新读取仓库状态，并可复制命令输出。
- **切换分支更直接。** 顶栏分支名旁新增「切换分支」按钮。选择器支持键盘搜索。同名本地分支与所选远端分支的上游不匹配时，可明确选择本地分支或用另一个名称创建跟踪分支。
- **刷新和浏览更流畅。** 同一分支刷新时保留变更列表、勾选和滚动位置。分支列表按需加载，连续点选文件时合并 Diff 预览请求。Git 历史先显示提交列表，文件 Diff 使用对应提交的哈希。
- **操作范围更明确。** 新仓库加载成功后才更新当前上下文，提交快捷键只在 Git 工作台激活时生效。
- **桌面和 Markdown。** macOS 使用系统窗口按钮，支持更窄的窗口和单面板 Git 布局。打开 Diff、历史和 Markdown 子窗口时省去重复的应用级初始化。快速打开多个 Markdown 文件时，始终显示最后选择的文档。

打包发布后，可在应用设置中检查更新，或从 GitHub Release 下载对应平台的安装包。

---

## English

This release makes Git operations safer on large repositories and improves the responsiveness of the workbench.

- Branch switching, merging, the local merge phase of Pull, and rebasing wait for Git to finish writing. Branch switches show the source, destination, and progress. The repository is refreshed after a failed switch, and command output can be copied.
- Switch branches directly beside the current branch. Search the picker with the keyboard. If a local branch with the same name tracks a different upstream, choose that local branch explicitly or create a tracking branch under a different name.
- Refreshes preserve the change list, selection, and scroll position on the same branch. Branches load on demand, rapid diff previews are coalesced, and Git history shows the commit list before loading details.
- Repository context changes only after a successful load. The commit shortcut is scoped to the active Git workbench.
- macOS now uses native window controls and supports a narrower layout. Auxiliary windows skip redundant app initialization, and Markdown keeps the latest file selection when reads overlap.
