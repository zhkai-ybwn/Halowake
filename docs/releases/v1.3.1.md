# Halowake v1.3.1 Release Notes

> **AI Coding 时代的本地开发伴侣 —— 全局 AI 额度状态中心统一、实时双向同步与三色状态模型重构、Markdown 离线渲染依赖加固**

---

## 🚀 版本亮点 (Highlights)

### 1. 🔄 全局 AI 额度状态管理与实时双向同步 (Pinia Quota Store)
- **数据收口与全链路响应式打通**：
  - 针对此前全屏额度中心（`AiQuotaView`）与顶部栏小胶囊（`TopbarQuotaPill`）各自持有孤立本地快照的问题，建立全局统一 Pinia 响应式状态中心（`useQuotaStore`）；
  - 无论在顶部栏气泡点击刷新，还是在全屏额度中心执行全量/单卡刷新，所有视图数据在同一帧内 **100% 保持严格一致**；
  - 彻底解决由于刷新异步导致的“右上角谷歌等额度与资产中心额度数值不一致（如 92%/80% 与 100%/81% 脱节）”问题。
- **智能防抖保鲜**：
  - 顶部栏气泡展开时自动监听并校验数据时效，数据超过 10 秒即触发静默拉新，确保每次展开均呈现最新鲜的算力水位。

### 2. 🚦 顶部栏健康度三色状态模型重构 (Traffic-Light Status Engine)
- **精准健康度算法**：
  - 废弃原有的 `warningAccountsCount > 0` 粗粒度判断，重构为基于各活跃账号 **5小时/每周限额剩余百分比**、**用量配速预测（Burn Rate）** 及 **可用余额** 的综合健康度计算模型：
    - 🟢 **健康状态 (`healthy` / 绿点)**：所有活跃账号限额剩余均 $> 30\%$，且使用节奏健康平稳；
    - 🟡 **偏紧告警 (`warning` / 黄点)**：任意活跃账号限额剩余 $\le 30\%$，或配速用量偏紧 (`tight`)；
    - 🔴 **严重告警 (`danger` / 红点)**：任意活跃账号限额剩余 $\le 10\%$、配速预计超标 (`overPace`) 或可用余额已耗尽；
    - ⚪ **闲置状态 (`idle` / 灰点)**：未配置任何活跃账号。
  - 彻底修复“百分比均为绿色健康状态，但右上角状态圆点一直常驻黄色”的显示 Bug。

### 3. 🛠️ Claude Code CLI 本地状态判定优化
- **消除假性“服务异常”**：
  - 优化本地扫描到 `~/.claude.json`、`~/.claude` 或 OAuth 会话但未填写 Anthropic API Key 时的状态处理；
  - 正确识别并标记为正常可用的本地凭证（`is_healthy = true`，显示 `Claude Code CLI` 计划），不再误报红色“服务异常”；
  - 细化自动发现探测逻辑，仅在检测到真实存在的认证凭据文件时才自动添加账号，避免空目录导致的无效账号占位。

### 4. 📦 Markdown 预览核心依赖显式收口与打包加固
- **生产构建稳定性加固**：
  - 显式声明并锁定 `dompurify`、`mermaid`、`highlight.js` 依赖，解决在特定生产打包环境下 Rollup/Vite 模块解析异常；
  - 确保离线无网络环境下流程图、时序图、架构拓扑图与代码高亮 100% 稳定解析与本地渲染。

### 5. 🧹 CI 门禁与代码规范全面治理
- 修复 TypeScript 严格模式下的未引用变量（`@typescript-eslint/no-unused-vars`）；
- 全面通过 `vue-tsc --noEmit`、`eslint .` 与 `stylelint` 检查，保证 0 Error 0 Warning 纯净构建。
