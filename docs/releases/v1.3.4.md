# Halowake v1.3.4 Release Notes

> **AI Coding 时代的本地开发伴侣 —— 新增 Xiaomi MiMo（小米大模型开放平台 / MiMo Code）全量额度适配器与本地凭据智能发现**

---

## 🚀 版本亮点 (Highlights)

### 1. ⚡ Xiaomi MiMo（小米大模型开放平台 / MiMo Code）深度适配
为满足广大开发者使用小米大模型（Xiaomi MiMo / MiMo Code）进行编程辅助与 API 调用的需求，v1.3.4 正式上线 Xiaomi MiMo 官方生态接入：

- **双模探测与本地凭据免密提取 (Zero-Config Local Discovery)**：
  - 支持全自动扫描开发者本地客户端与开发环境凭据：
    - Windows: `%LOCALAPPDATA%\mimocode\auth.json` 及 `%APPDATA%\Xiaomi MiMo\auth.json`；
    - macOS / Linux: `~/.local/share/mimocode/auth.json` 及 `~/.config/mimocode/auth.json`；
  - 自动安全提取认证凭证（API Key）及关联的自定义 `metadata.base_url`；
  - 支持联动本地 `ai-settings.json`，自动将既有的小米大模型配置同步加入额度监控看板。

- **多端点自适应健康探测与余额/模型解析 (Adaptive Quota Engine)**：
  - **连通性校验**：自动校验 API Key 状态，探测 `/v1/models` 获取实时可用模型总数；
  - **多协议余额解析**：自适应兼容 `/user/balance`、`/account/balance`、`/billing/balance` 等常见计费接口，无缝支持 DeepSeek 格式、SiliconFlow 格式及标量余额结构；
  - **优雅无缝降级**：若开放平台未暴露公网余额端点，自动智能降级为展示「X 个可用模型 · 额度见控制台」，不捏造虚假数值，同时提供一键直达官方控制台的便捷链接。

- **客户端一键调起与系统无缝集成 (Client Launcher)**：
  - 在额度看板中支持一键拉起本地安装的 **Xiaomi MiMo / MiMo Code** 客户端；
  - 精准覆盖 Windows 及 macOS 平台的可执行程序与启动路径规则。

- **原生视觉与全链路品牌规范 (Brand Identity & macOS Design)**：
  - 定制专属 Xiaomi MiMo 经典活力橙品牌矢量图标（`#FF6700`）；
  - 全屏额度中心卡片、顶部状态胶囊（`TopbarQuotaPill`）、账号管理与编辑抽屉全链路视觉适配；
  - 本地客户端分类过滤器与一键扫描提示文本同步收录 Xiaomi MiMo。

## 🛠️ 详细变更清单 (Changelog)

- `src-tauri/src/quota/adapters/mimo.rs`：**[NEW]** 新增 Xiaomi MiMo 额度适配器，覆盖本地凭证读取、多端点余额自适应解析与可用模型连通性探测；
- `src-tauri/src/quota/adapters/mod.rs`：注册导出 `mimo` 模块；
- `src-tauri/src/quota/discovery.rs`：新增 Xiaomi MiMo 本地凭据与 `ai-settings.json` 自动发现机制；
- `src-tauri/src/quota/manager.rs`：在单账号/全量额度拉取流程中接入 `fetch_mimo_quota`；
- `src-tauri/src/quota/models.rs`：`ProviderType` 新增 `Mimo` 枚举，配置官方控制台地址与标准显示名称；
- `src-tauri/src/commands/client_launcher.rs`：注册 `Xiaomi MiMo` 客户端拉起规则；
- `src/components/quota/ProviderBrandLogo.vue`：新增 Xiaomi MiMo 官方高精矢量品牌 Logo；
- `src/components/quota/QuotaCard.vue`：适配 MiMo 品牌色彩、副标题及客户端快速拉起能力；
- `src/components/quota/TopbarQuotaPill.vue`：适配 MiMo 顶部栏胶囊展开背景与品牌色；
- `src/components/quota/AccountEditModal.vue` / `AccountManageModal.vue`：新增 MiMo 账号类型选项及 API Key 智能占位提示；
- `src/services/quota/quota-service.ts`：前端类型定义补充 `mimo`；
- `src/views/quota/AiQuotaView.vue`：将 `mimo` 纳入本地客户端过滤器 `LOCAL_CLIENT_PROVIDERS`；
- `src/i18n/messages/zh-CN.ts` / `en-US.ts`：更新本地扫描提示文案，包含 Xiaomi MiMo；
- `package.json` / `src-tauri/tauri.conf.json` / `src-tauri/Cargo.toml`：升级版本至 `1.3.4`；
- `src-tauri/Cargo.lock`：同步锁文件版本至 `1.3.4`。

## 📦 安装与升级 (Installation)

### 方式一：应用内无缝自动更新（推荐）
- 已安装旧版本的用户在应用内点击 **检查更新**，即可自动拉取并无缝热升级至 `v1.3.4`。

### 方式二：下载桌面安装包
前往 [GitHub Releases](https://github.com/zhkai-ybwn/Halowake/releases/tag/v1.3.4) 下载对应平台的安装程序：
- **Windows**: `Halowake_1.3.4_x64-setup.exe` (NSIS 安装包，无缝覆盖安装)
- **macOS**: `Halowake_1.3.4_universal.dmg` (Apple Silicon M系列与 Intel 通用镜像)
- **Linux**: `Halowake_1.3.4_amd64.deb` / `.AppImage`
