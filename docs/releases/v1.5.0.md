# Halowake v1.5.0

发布于 2026-11-06。

本版本精简功能，聚焦跨 Agent 工作记录、项目服务、Git 提交与 Skills 管理，并带来历史读取和界面响应优化。

## 功能调整

- 移除 Token 钱包（AI 额度中心）、供应商额度查询、账号管理和后台自动刷新。
- 移除 Codex 定时与手动预热。升级后，旧版配置的预热计划停止执行。
- 移除内置代码审查、文件评分、推荐筛选、审查规则管理和审查模型配置。
- Git Assistant 支持查看 Working Tree / Staged / HEAD Diff、勾选文件、生成与编辑提交信息、按所选文件提交。切换 Diff 查看对象与提交勾选独立，其他文件原有的暂存状态在按文件提交后恢复。
- 旧版额度账户与审查历史保留在本地数据库，过期且未固定的审查记录继续遵循原有清理规则。

## 响应与稳定性

- 历史会话解析增加有容量上限的进程内缓存，文件发生变化后重新解析，超出容量的文件继续流式读取。
- 工作记录支持明确选择零个项目，修复取消全选、反选与旧偏好迁移。压缩的 Claude 子代理记录按身份去重。
- 部分 OpenCode 数据源读取失败时，展示正常来源和可重试提示。
- 页面与 Skills 弹窗按需加载，Markdown 按需加载图表渲染，降低初始加载量。
- DevDock 和 Markdown 在页面停用或窗口隐藏时暂停轮询。日志版本未变化时省略重复正文传输。
- 大型 Diff 仅渲染可见行与缓冲行。进程停止与重启的阻塞操作移至后台线程。

## 验证与已知限制

- 前端类型、ESLint、Stylelint 检查及生产构建通过，68 项单元测试通过。
- Rust 库测试 122 项通过，1 项合成性能基准默认跳过。确定性 Skills 搜索集成测试 11 项通过。
- 本机真实 Skills 目录上的两项排序基准仍未通过。React 单元测试查询的首位结果与预期不同，30 条回归集的严格首位命中率为 46.2%，低于 95% 门槛。此次发行沿用既有搜索实现。
- 浏览器与桌面界面仍待人工验收。构建保留 Vite 大分块和混合导入提示。

## English

Version 1.5.0 removes the Token Wallet / AI Quota Center, Codex warmup, and built-in code review. Halowake focuses on cross-agent work records, project services, Git commits, and Skills management.

- Git Assistant supports diff viewing, file selection, commit message generation and editing, and committing selected files. Switching the displayed diff is independent of commit selection. Selected-file commits restore the other files' existing staged state.
- Previously configured Codex warmup schedules stop running after upgrading. Legacy quota accounts and review history stay in the local database, with expired, unpinned review records following the existing cleanup policy.
- Session parsing uses a bounded in-memory cache. Work report filtering supports zero selected projects, deduplicates compressed Claude subagent records, and reports partial OpenCode loading failures.
- Pages, the Skills dialog, and Markdown diagrams load on demand. Background polling follows page visibility, unchanged logs avoid repeated transfer, and large diffs render only visible rows with a buffer.
- Frontend checks, production build, and all 68 frontend tests passed. Rust library tests passed 122 cases with one benchmark ignored, and all 11 deterministic search integration tests passed.
- Two ranking benchmarks against the local Skills catalog remain below expectations, including strict top-result accuracy of 46.2% against a 95% threshold on the regression set. Browser and desktop UI verification remains manual.
