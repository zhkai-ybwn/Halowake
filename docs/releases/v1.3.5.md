# Halowake v1.3.5 Release Notes

> **AI Coding 时代的本地开发伴侣 —— Antigravity 会话项目精准识别重构、历史与跨日会话加载性能极致跃升、全链路日期范围 0 毫秒截断缺陷根治**

---

## 🚀 版本亮点 (Highlights)

### 1. 🎯 Antigravity 会话所属项目识别精准重构 (Zero-Misclassification Project Inference)
解决在多项目混合开发场景下，Antigravity 会话归属项目被误判的问题：
- **SQLite 官方关系映射 (Deterministic Metadata Association)**：深度集成 Antigravity 本地 SQLite 状态库（`state.vscdb` 中的 `conversations` 与 `workspace_project_relationships` 表），建立会话 ID 到所属项目目录的确定性关联；
- **执行路径优先原则 (Tool Execution Directory Priority)**：会话所属项目优先以 Agent 实际执行的工具工作目录（`SearchDirectory`、`TargetFile`、`Cwd`）为准；
- **日志噪声文本免疫 (Log Noise Immunity)**：彻底规避因用户在 Prompt 或提问中粘贴其他项目的报错日志（如包含其他工程路径）而导致的贪婪误判，保证项目归属 100% 准确。

### 2. ⚡ AI 工作日报/周报读取性能与历史会话加载根治 (High-Performance History Engine)
针对会话记录加载变慢及历史记录漏读问题，完成底层扫描引擎全面重构：
- **解决 Windows 平台跨日会话漏读 (Cross-Day Session Retrieval)**：针对 Codex CLI 在 Windows 上继续历史会话时不更新文件 `LastWriteTime`（修改时间停留在初始创建日）的系统特性，移除存在缺陷的文件 mtime 粗筛，确保所有跨日、历史继续会话完整读出；
- **多线程并行分块扫描 (Multithreaded Parallel Parsing)**：基于 `std::thread::scope` 实现多核心并行并发解析，结合智能时间目录剪枝与零内存分配切片查找（`fast_extract_timestamp`），扫描读取性能跃升数倍，历史周报加载从数秒降至毫秒级。

### 3. 🗓️ 日期范围选择器 0 毫秒截断致命缺陷根治 (Full-Day Range Normalization)
- **单日/区间选择全天覆盖**：彻底修复 Naive UI 日期范围组件（`type="daterange"`）自动将结束日期归一化为当天的零点 `00:00:00.000`、导致单日查询区间长度为 0 毫秒、拦截当天所有工作记录的缺陷；
- **全链路时区与时间边界对齐**：前端与 Rust 后端全链路将结束时间自适应延伸至当天的 `23:59:59.999`，无论用户查询单日还是多日跨度，均精准覆盖 24 小时内的所有 AI 编程记录。

### 4. 🎨 工作台 UI/UX 体验与空状态交互优化 (macOS Workbench Polish)
- **过滤状态智能引导**：当多选项目筛选导致列表为空时，提供一键「显示全部项目」的快捷重置操作；
- **项目筛选器高亮反馈**：当处于自定义项目筛选状态时，顶部项目按钮呈现激活品牌色视觉标识；
- **布局稳定性加固**：加固左右工作区分栏与侧边栏折叠结构，保障不同分辨率下的沉浸式开发体验。

## 🛠️ 详细变更清单 (Changelog)

- `src/views/codex-report/CodexReportView.vue`：
  - 新增 `handleDateRangeUpdate`，修复 Naive UI 日期范围选择器结束日期自动归零缺陷；
  - `loadSessions` 自动对齐结束日期至 `23:59:59.999`；
  - 恢复并加固 `.workspace-shell` 左右工作区分栏布局与项目配置按钮筛选激活态样式；
  - 增加空过滤状态下一键展示全部项目的快捷操作；
- `src-tauri/src/commands/codex_report.rs`：
  - 接入 SQLite 状态库元数据读取，精准解析 Antigravity 会话与项目关联；
  - 优化项目推断算法，屏蔽提问中日志报错路径的干扰，优先工具执行工作区；
  - 移除 Windows 平台失效的 Codex 会话文件修改时间预过滤，修复跨日继续会话漏读；
  - 实现零内存分配时间戳提取与多线程并行分块会话解析；
  - 后端接口增强防御性日期对齐；
  - 新增针对跨日继续会话加载与 Antigravity 日志隔离的完备单元测试套件；
- `src/i18n/messages/zh-CN.ts` / `en-US.ts`：补充「显示全部项目」多语言翻译词条；
- `package.json` / `src-tauri/tauri.conf.json` / `src-tauri/Cargo.toml`：升级版本至 `1.3.5`；
- `src-tauri/Cargo.lock`：同步锁文件版本至 `1.3.5`。

## 📦 安装与升级 (Installation)

### 方式一：应用内无缝自动更新（推荐）
- 已安装旧版本的用户在应用内点击 **检查更新**，即可自动拉取并无缝热升级至 `v1.3.5`。

### 方式二：下载桌面安装包
前往 [GitHub Releases](https://github.com/zhkai-ybwn/Halowake/releases/tag/v1.3.5) 下载对应平台的安装程序：
- **Windows**: `Halowake_1.3.5_x64-setup.exe` (NSIS 安装包，无缝覆盖安装)
- **macOS**: `Halowake_1.3.5_universal.dmg` (Apple Silicon M系列与 Intel 通用镜像)
- **Linux**: `Halowake_1.3.5_amd64.deb` / `.AppImage`
