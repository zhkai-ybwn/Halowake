# Halowake v1.3.3 Release Notes

> **AI Coding 时代的本地开发伴侣 —— 根治 Mermaid 图表异常解析全局 DOM 泄漏缺陷，加固 Markdown 文档跨路由沉浸式浏览体验**

---

## 🚀 版本亮点 (Highlights)

### 🛡️ 彻底消除 Mermaid 语法解析失败后的全局 DOM 污染 (Suppress Error Leaks)
- **问题背景**：
  - 在此前版本中，当 Markdown 文档中的流程图、时序图或架构拓扑图存在语法错误（或处于编辑草稿态）时，底层的 Mermaid 11 渲染引擎会在应用的 `document.body` 根节点上临时挂载一个全局错误 SVG 提示框；
  - 由于 Mermaid 内部在解析异常退出时未主动清理该临时节点，导致该红色错误横幅常驻于整个应用窗口顶层，无论用户切换路由至 **Git 助手**、**DevDock 容器管理** 还是 **AI 算力额度中心**，都会受到该残留错误节点的视觉干扰。
- **治理与修复**：
  - 在 `MarkdownDocumentViewer` 的 `mermaid.initialize` 配置中显式启用 `suppressErrorRendering: true`，全面阻断 Mermaid 底层向宿主 `document.body` 注入全局非预期 DOM 的行为；
  - 充分利用 Halowake 原生设计的卡片级局部错误兜底机制（`.md-mermaid-error`），在图表语法有误时以优雅、低噪的局部卡片展示语法告警，并无缝提供“展开/隐藏原始代码”切换功能；
  - 既保障了开发者在阅读损坏图表时获取准确的调试反馈，又彻底杜绝了错误信息跨视图、跨路由泄漏的缺陷。

## 🛠️ 详细变更清单 (Changelog)

- `src/views/markdown-preview/components/MarkdownDocumentViewer.vue`：
  - `mermaid.initialize` 注入 `suppressErrorRendering: true`，屏蔽 Mermaid 11 默认向 `document.body` 插入错误 SVG 的侵入式行为；
  - 保持局部卡片级语义化告警状态与代码回退视图。
- `package.json`：升级应用版本至 `1.3.3`；
- `src-tauri/tauri.conf.json`：升级应用版本至 `1.3.3`；
- `src-tauri/Cargo.toml`：升级 Cargo 包版本至 `1.3.3`；
- `src-tauri/Cargo.lock`：同步更新锁文件版本至 `1.3.3`。

## 📦 安装与升级 (Installation)

### 方式一：应用内无缝自动更新（推荐）
- 已安装旧版本的用户在应用内点击 **检查更新**，即可自动拉取并无缝热升级至 `v1.3.3`。

### 方式二：下载桌面安装包
前往 [GitHub Releases](https://github.com/zhkai-ybwn/Halowake/releases/tag/v1.3.3) 下载对应平台的安装程序：
- **Windows**: `Halowake_1.3.3_x64-setup.exe` (NSIS 安装包，无缝覆盖安装)
- **macOS**: `Halowake_1.3.3_universal.dmg` (Apple Silicon M系列与 Intel 通用镜像)
- **Linux**: `Halowake_1.3.3_amd64.deb` / `.AppImage`
