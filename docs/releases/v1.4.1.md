# Halowake v1.4.1 Release Notes

> **AI Coding 时代的本地开发伴侣 —— Agent 技能中心 2.0 重构演进、技能安全卸载与安装历史审计、Agent 存储空间分析与缓存清理中枢、多端矢量图标离线秒开优化**

---

## 🚀 版本亮点 (Highlights)

### 1. 🔮 Agent 技能中心 2.0 重大演进 (Skill Hub 2.0 & Decoupled Architecture)
全面重构技能探索与管理生态，让技能发现与分发更加轻盈、健壮与高效：
- **注册表与爬虫完全解耦**：将原本内置的重型爬虫解耦为独立的技能注册表架构与独立仓库，应用内通过动态 Registry 适配器连接，实现本地 SQLite 高速快照缓存与轻量增量同步，大幅减小应用体积并彻底消除网络波动卡顿；
- **双视图自由切换与精细化分页**：探索区提供网格卡片（`SkillCard`）与紧凑行列表（`SkillCompactRow`）双视图切换；重构分页与跳页控件，在海量技能生态下依然保持极简高效的浏览体验；
- **智能镜像源与文档容灾回退**：新增技能来源向导（`skill-source-guide`），集成 GitHub Raw 与 jsDelivr 等多镜像容灾机制，支持一键在应用内预览技能 Markdown 原生文档；
- **个性化视觉锚点与领域识别**：基于技能所属职能关键词（Git/Review、Test/QA、Deploy/CI、UI/Design、Doc/Writing）与研发生命周期阶段，自动分配专属配色方案与 Solar 矢量图标，告别单一图标同质化；
- **离线图标集秒开渲染**：构建前自动预打包 134 个 Solar 与 MDI 矢量图标集合，彻底摆脱外部网络请求，实现首屏零延迟瞬时渲染。

### 2. 🛡️ 技能安全卸载与安装历史追溯 (Safe Uninstall & Install History Audit)
解决 Agent 技能“只装难卸、来源难寻”的长期痛点，带来企业级安全与可审计性：
- **受管目录与安全边界防线**：后端严格限制仅能卸载白名单受管根路径下的直接技能子目录，彻底防御软链接穿越与意外删除父级目录的风险；
- **外部包管理锁检测与智能引导**：自动识别 `skills` CLI 或外部包管理器管理的技能，引导返回原包管理器处理，防止外部元数据脱节；
- **本地修改防护警告**：实时感知技能源码的本地脏改动（`is_dirty`），在卸载前主动展示警告与影响的 Agent 列表；
- **全生命周期安装历史审计**：新增“安装历史”标签页，基于 SQLite `skill_install_history` 审计表，完整回溯每次安装的时间戳、Git 源地址、目标 Agent、工程路径与安装结果，并支持历史记录智能兼容迁移。

### 3. 💾 全新 Agent 存储空间分析与缓存清理中枢 (Agent Storage & Cache Cleaner)
针对主流 AI 编程助手长期运行导致磁盘占用暴涨的问题，提供一站式洞察与清理方案：
- **跨平台原生探测**：覆盖 Windows、macOS 与 Linux 三大操作系统，精准扫描 Cursor、Codex、Antigravity、Claude Code、Trae、Cline、Windsurf 等核心 Agent 的数据与缓存根目录；
- **类 `dua` 磁盘目录体积剖析**：单层子目录占用深度排行，直观展示各 Agent 的模型缓存、历史索引、临时构建物与日志所占空间，并规避重叠路径重复计算；
- **安全缓存一键清道夫**：精确定位各类 Agent 的临时缓存目录，支持一键安全清理并跳过符号链接与占用文件，快速释放数 GB 宝贵系统磁盘空间。

### 4. 🪟 Markdown 独立窗口与双端联动体验升级
- 优化 Markdown 独立查看窗口与主窗口的通信及多屏协同体验；
- 增强本地文档渲染与目录定位能力，提供更加沉浸的规范与文档查阅体验。

### 5. ⚡ Git 助手与 DevDock 体验持续打磨
- **DevDock 日志检索**：优化日志模态框关键词高亮、行数计数与级别过滤表现；
- **Git 远程与分支操作强化**：增强远程分支与凭据处理鲁棒性，丰富 Git 命令弹窗交互细节。

## 🛠️ 详细变更清单 (Changelog)

### 新增与核心功能 (Features & Enhancements)
- `src-tauri/src/commands/agent_storage.rs`：新增 Agent 存储空间深度探测与缓存清理原生后端实现；
- `src-tauri/src/commands/skill_registry.rs` & `src-tauri/src/storage/skill_registry_repository.rs`：新增技能注册表快照加载、保存与 SQLite 持久化支持；
- `src-tauri/src/commands/skills.rs`：增强技能安全卸载边界校验、CLI 锁检测、源码脏改动校验与安装历史查询接口；
- `src-tauri/src/storage/migrations.rs`：新增技能注册表、安装历史数据表迁移，以及历史版本 `display_name` 容灾升级逻辑；
- `src/components/settings/panels/AgentStoragePanel.vue`：全新 Agent 存储空间分析面板；
- `src/components/skills/explore/SkillCompactRow.vue`：新增技能探索紧凑列表视图组件；
- `src/components/skills/installed/SkillInstallHistoryView.vue`：新增技能安装历史回溯组件；
- `src/services/skills/`：新增 `registry-cache.ts`、`skill-source-guide.ts`、`skill-markdown-preview.ts`；
- `src/utils/skill-visuals.ts` & `src/utils/skill-category-label.ts`：实现基于领域与阶段的个性化色彩和图标计算；
- `scripts/generate-icon-collection.mjs`：离线矢量图标打包脚本，集成至 `predev` 与 `prebuild` 流程。

### 优化与缺陷修复 (Improvements & Fixes)
- `src/components/skills/explore/SkillExploreView.vue`：紧凑重构分页与跳页控件，优化筛选状态持久化；
- `src/components/skills/installed/InstalledSkillsView.vue`：集成安全卸载确认流程与安装历史入口；
- `src/components/skills/explore/SkillDetailDrawer.vue` & `SkillInstallModal.vue`：优化安装目标选择与多镜像回退加载；
- `src/i18n/messages/zh-CN.ts` & `en-US.ts`：全量补齐技能注册中心、安全卸载、存储清理与安装历史中英文国际化条目；
- `package.json`, `src-tauri/Cargo.toml`, `src-tauri/tauri.conf.json`, `src-tauri/Cargo.lock`：版本号统一升级至 `1.4.1`。

## 📦 安装与升级 (Installation)

### 方式一：应用内无缝自动更新（推荐）
- 已安装用户在应用内点击 **检查更新**，即可自动拉取并无缝热升级至 `v1.4.1`。

### 方式二：下载桌面安装包
前往 [GitHub Releases](https://github.com/zhkai-ybwn/Halowake/releases/tag/v1.4.1) 下载对应平台的安装程序：
- **Windows**: `Halowake_1.4.1_x64-setup.exe` (NSIS 安装包，无缝覆盖安装)
- **macOS**: `Halowake_1.4.1_universal.dmg` (Apple Silicon M系列与 Intel 通用镜像)
- **Linux**: `Halowake_1.4.1_amd64.deb` / `.AppImage`
