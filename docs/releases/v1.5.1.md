# Halowake v1.5.1

本次补丁修复 Git 助手在批量提交时长时间没有进度反馈的问题，并改善大仓库中的分支切换、状态刷新和 Diff 查看。

- 提交开始即显示文件校验，随后更新暂存、提交和恢复暂存区等阶段。等待 Git 或提交钩子时显示活动条。
- 批量校验选中文件和读取提交说明所需的 Diff，减少 Git 进程启动次数。按文件提交会保留其他文件原有的暂存内容。
- 修复大量换行符差异导致 Windows 切换分支时命令行过长的问题。
- 仓库刷新先显示变更列表，后台补充行数统计。长列表按可见范围渲染。
- 独立 Diff 和日志窗口各加载一次。Diff 默认显示变更，完整文件上下文可按需展开。

在应用设置中检查更新，或从发布附件下载对应平台的安装包。

---

## English

This patch fixes missing progress feedback during large Git commits and improves branch switching, repository refreshes, and diff viewing in large repositories.

- The commit dialog shows file validation immediately, followed by staging, committing, and restoring the index. It shows an activity indicator while waiting for Git or a commit hook.
- Batched file validation and diff reads reduce Git process launches. Committing selected files preserves existing staged changes in other files.
- Fixed Windows branch switching when many line-ending differences would exceed the command-line length limit.
- Repository refreshes show the changed files before line counts are ready. Large lists render rows near the visible area.
- Diff and log windows load once per request. The diff window shows changes first and lets you expand the full file context.

Check for updates in the app settings, or download the installer for your platform from the release assets.
