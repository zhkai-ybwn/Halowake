# 额度工作台 UI 与本地客户端启动设计

## 目标

将额度页从高密度监控大屏收敛为跨平台桌面工作台：用户先看到账号健康状态和关键资产，再通过卡片上的上下文操作打开本地客户端或官方控制台。

## 范围

- 将五张大统计卡压缩为一条状态概览。
- 顶部只保留刷新和新增账号；低频的管理、扫描和自动刷新设置进入更多菜单。
- 主筛选改为全部、需要处理、本地客户端和 API 资产。
- 卡片按自身内容高度排列，避免同一行被最高卡片拉伸。
- 卡片提供有文字的主操作；编辑、单独刷新等低频操作进入更多菜单。
- 对 Cursor、Qoder、ZCode、Trae、WorkBuddy 和 Antigravity 提供安全的跨平台启动能力。启动成功后仅自动重试一次当前账号额度。

## 启动边界

后端仅接受受控的 ProviderType，不接受任意命令或参数。Windows 使用已验证的安装候选路径和 PATH 命令；macOS 使用 `open -a` 的固定应用名；Linux 使用固定命令名。启动桌面应用通常会激活已有单实例窗口，因此不额外引入平台窗口管理依赖。

如果未找到客户端，前端保留官方控制台入口并显示明确错误。Web/API Provider 不进入本地启动流程。

## 验证

- Rust 单元测试验证 Provider 到跨平台启动定义的映射，以及 Web Provider 被拒绝。
- TypeScript/Vue 通过项目 Lint 与 Build。
- Rust 执行完整测试和 Clippy。
- 按项目约束不执行浏览器自动化；Windows 实机视觉和应用聚焦由用户确认。
